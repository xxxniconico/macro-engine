## 三、维度I：企业质量（35%）

> **方法论依据**：巴菲特的"以合理价格买优秀企业"——先看企业好不好，再谈价格。  
> **学术依据**：Buffett's Alpha 中 QMJ（Quality Minus Junk）因子解释超额收益。

### Q1: ROE 稳定性（12%）

**公式**：5年ROE均值，通过杜邦拆解验证质量

```
ROE_5y = mean(roe[-5:])
    
# 杜邦拆解辅助判断
dupont = {
    '净利率': net_income / revenue,
    '周转率': revenue / total_assets,  
    '杠杆': total_assets / equity
}
# 高杠杆驱动的高ROE需警惕（金融股除外）
```

**计分**：min(ROE_5y, 30%) / 30% × 10

| ROE范围 | 得分 | 定性 |
|---------|:--:|------|
| >25% | 9-10 | 卓越 — 可口可乐级别 |
| 15-25% | 7-8 | 优秀 |
| 8-15% | 4-6 | 合格 |
| <8% 且 >0 | 1-3 | 不达标 |
| <0 | 0 | 一票否决 |

**学术来源**：Frazzini et al. (2018) RMW因子；Novy-Marx (2013) 盈利性是核心质量维度

### Q2: ROIC 超额收益（10%）

**公式**：ROIC - WACC 的跨周期均值

```
ROIC = NOPAT / Invested_Capital
NOPAT = EBIT × (1 - 0.25)  # 近似税率25%
Invested_Capital = 股东权益 + 有息负债 - 超额现金

简化版（无WACC数据时）：
ROIC_5y = mean(EBIT[-5:] / (equity[-5:] + debt[-5:]))
得分 = min(ROIC_5y, 30%) / 30% × 10
```

| ROIC范围 | 得分 |
|----------|:--:|
| >25% | 9-10 |
| 15-25% | 7-8 |
| 10-15% | 4-6 |
| 5-10% | 1-3 |
| <5% | 0 |

**学术来源**：Greenblatt Magic Formula (2005) 核心因子；Buffett's Alpha 盈利性维度

### Q3: CFO 真实性（8%）

**公式**：经营现金流与净利润的一致性检验

```
CFO_quality = mean(ocf[-3:]) / mean(ni[-3:])  # 近3年均值
得分 = min(CFO_quality, 2.0) / 2.0 × 10
```

| CFO/NI | 得分 | 含义 |
|--------|:--:|------|
| >1.5 | 9-10 | 保守会计，现金流强劲 |
| 0.8-1.5 | 6-8 | 健康 — 利润有现金支撑 |
| 0.4-0.8 | 3-5 | 警惕 — 应收/存货可能在堆积 |
| <0.4 | 0-2 | 高风险 — Sloan效应 |

**学术来源**：Sloan (1996) 应计异象；Piotroski F-Score #2、#4；在A股尤其重要——财务造假常体现在现金流与利润背离

### Q4: 毛利率护城河（5%）

**公式**：毛利率水平 × 稳定性

```
GM_median = median(gm[-3:])         # 近3年中位数
GM_rank = percentile(gm_median)     # 全市场分位数
GM_stability = 1 - stdev(gm[-5:])/mean(gm[-5:])  # 稳定性系数

得分 = (GM_rank × 8) + (GM_stability × 2)  # 水平8分 + 稳定2分
```

**学术来源**：巴菲特"定价权"核心特征；毛利率稳定性 = 护城河耐久性代理

## 四、维度II：估值水平（30%）

> **方法论依据**：安全边际——"用40美分买1美元的东西"  
> **学术依据**：Fama-French HML因子；Acquirer's Multiple 回测年化超额6-8%

### V1: EV / Operating Earnings（15%）— 最重要的估值锚

**公式**：

```
OpEarnings = 营业利润 + 折旧摊销 + 财务费用  # 近似美国口径

EV = 总市值 + 总负债 - 现金 - 长投×0.5

因子值 = EV / OpEarnings
得分 = (15 - min(因子值, 15)) / 15 × 10
```

| EV/OpE | 得分 | 定性 |
|--------|:--:|------|
| <1.5x | 9-10 | 极度低估 |
| 1.5-4.5x | 7-8 | 显著低估 |
| 4.5-8x | 4-6 | 合理偏低 |
| 8-15x | 1-3 | 合理偏高 |
| >15x | 0 | 太贵 |

**学术来源**：Carlisle (2014) Acquirer's Multiple — 比PE更稳健（EV含债务），比PB更本质（直估运营盈利能力）

### V2: FCF Yield（10%）

**公式**：

```
FCF = OCF - Capex  # 简化：经营现金流 - 购建固定资产支出
FCF_Yield = FCF / 总市值
得分 = min(FCF_Yield, 0.15) / 0.15 × 10
```

| FCF Yield | 得分 | 定性 |
|-----------|:--:|------|
| >12% | 9-10 | 极佳 |
| 8-12% | 7-8 | 优秀 |
| 4-8% | 4-6 | 良好 |
| 0-4% | 1-3 | 一般 |
| <0 | 0 | — |

**学术来源**：Buffett's Alpha 通过QMJ间接体现；Damodaran: FCF Yield是最干净的估值指标；巴菲特Owner Earnings的近似

### V3: PB 行业调整（5%）

**公式**：

```
因子值 = PB / 行业PB中位数
得分 = max(0, 1 - 因子值) × 10
```

| 行业 | 特殊处理 |
|------|---------|
| 金融(银行/保险/券商) | PB权重升至12%，EV/OpE降至8% |
| 轻资产(互联网/软件) | PB权重降至3%，差额加到EV/OpE |
| 地产 | 用PB，同时检查NAV折价 |
| 周期股 | 用近10年PB分位数替代行业对比 |

## 五、维度III：财务健康（20%）

### H1: 杠杆率（8%）

```
debt_ratio = 总负债 / 总资产
得分 = max(0, 1 - debt_ratio/0.70) × 10
```

| 负债率 | 得分 |
|--------|:--:|
| <30% | 8-10 |
| 30-50% | 5-7 |
| 50-70% | 2-4 |
| >70% | 0-1 |

*金融行业不适用，权重分配给H2*

### H2: 利息覆盖倍数（7%）

```
IC = (营业利润 + 财务费用) / 利息支出
得分 = min(IC, 20) / 20 × 10
```

| IC | 得分 |
|----|:--:|
| >15x | 9-10 |
| 8-15x | 6-8 |
| 3-8x | 3-5 |
| <3x | 0-2 |

### H3: 资产质量（5%）

```
# 检查：应收账款/营收 + 存货/总资产 + 商誉风险
AR_ratio = AR[-1] / revenue[-1]    # 应收占比
Inv_ratio = inventory[-1] / assets[-1]  # 存货占比
Goodwill_ratio = goodwill[-1] / equity[-1]  # 商誉风险

得分 = (max(0, 1-AR_ratio/0.5) + max(0, 1-Inv_ratio/0.4) + max(0, 1-Goodwill_ratio/0.3)) / 3 × 10
```

## 六、维度IV：治理与边际（15%）

### G1: 股东回报（8%）

```
# 分红 + 回购（A股简化为分红率）
dividend_yield = 每股分红 / 股价
buyback = equity[-1] < equity[-2] × 0.98  # 股本缩减

得分 = min(dividend_yield, 0.05) / 0.05 × 7  # 分红占7分
     + (3 if buyback else 0)                # 回购占3分
```

### G2: 审计与治理（7%）

```
得分 = 0
+ 3分 if audit_opinion == 'standard' and big4_auditor
+ 2分 if audit_opinion == 'standard' and not big4
+ 2分 if insider_ownership > 30%   # 内部人持股高 = 利益一致
- 3分 if related_party_transaction > revenue × 0.3  # 关联交易异常
```

| 行业 | 质量权重 | 估值权重 | 健康权重 | 治理权重 | 特殊规则 |
|------|:--:|:--:|:--:|:--:|------|

## 八、宏观联动：Dalio 引擎 × BQAS

BQAS 选股 + Dalio 引擎定仓位。Dalio 的风险得分动态调整 BQAS 的最终仓位比例。

| Dalio 风险得分 | 宏观阶段 | BQAS 权益仓位 | 附加规则 |
|:--:|------|:--:|------|
| <25 | 🟢 正常增长 | 60-70% | BQAS Top 30 等权 |
| 25-40 | 🟡 中性 | 40-50% | BQAS Top 20，偏防御行业 |
| 40-60 | 🟠 谨慎 | 20-30% | BQAS Top 10，优先高分红 |
| 60-80 | 🔴 防御 | 10-15% | 仅选必需消费+公用事业 |
| >80 | 💀 极端 | 0-5% | 停止股票池，全转现金/黄金 |

**联动机制**：
- 每月初取 Dalio 引擎最新 risk_score → 查表得仓位上限
- BQAS 按得分排序取 Top N（N = 仓位上限对应的数量）
- 当 Dalio 阶段从"正常"切换到"防御"时，自动减半仓
- 当 Dalio 阶段从"极端"恢复到"谨慎"时，分3个月逐步加仓

## 十、回测框架设计

### 回测参数

```
回测期间: 2015-01 ~ 至今
再平衡频率: 季度（3/6/9/12月末）
交易成本: 0.15%（印花税+佣金）
基准: 沪深300 全收益指数

选股池: 全A股 → 一票否决过滤 → BQAS得分 → 取Top 30
加权方式: 等权（稳健） / 波动率倒数（优化）
```

### 核心评估指标

| 指标 | 合格标准 | 优秀标准 |
|------|:--:|:--:|
| 年化超额收益 | >5% | >10% |
| 夏普比率 | >0.6 | >1.0 |
| 信息比率 | >0.8 | >1.5 |
| 最大回撤 | <35% | <25% |
| 年度胜率 | >60% | >75% |
| 因子IC均值 | >0.03 | >0.05 |
